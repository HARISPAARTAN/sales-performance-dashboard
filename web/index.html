About this replica

Demo with invented data for a fictional company. Veltrano Outdoor is a fictional outdoor-equipment wholesaler in Innsbruck, Austria, that sells tents, sleeping gear, backpacks, apparel, footwear and cooking gear to about 400 retailers in 13 European countries.

Sources

  • Three yearly order exports (data/sales_orders/sales_orders_2023.xlsx to _2025.xlsx, 2 January 2023 to 30 September 2025) and the monthly targets per region (data/targets.csv, to December 2025).
  • Products, customers, regions, sales reps and the security table as CSV files, all written by tools/make_data.py with seed 41.

Model

  • The Power BI model is a star schema: FactSales and FactTargets with DimDate, DimProduct, DimCustomer, DimRegion and DimSalesRep.
  • A calculation group Time intelligence (Current, PY, YoY, YoY %, YTD, PYTD, R12), a field parameter Analyse by and the role Regional manager (dynamic row-level security).
  • This page computes the same measures in JavaScript from replica.json, built by tools/build_replica_data.py through the Python reference; a parity test compares every tab with the reference. Row-level security exists only in the report.

Rules

  • Whole months only; a year with months still to come compares like for like with the same months of the previous year.
  • YoY is blank without a full previous year in the data (2023); a tile then shows n/a with the reason.
  • Targets are set per region and month, so the category filter does not apply on the Customers and Targets tabs.
